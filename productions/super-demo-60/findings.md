# Findings: Super Demo 60

## For Lee (product)

### Import flow needs an "import another" affordance (2026-08-03)

Seeding a KB from many documents means Seed Knowledge Base, Import file, browse, Upload, review, Commit, Close, thirteen times. The success state requires a manual Close before the next import can start (it blocked the first automated run). A "commit and import another" button would smooth from-zero seeding, which the Aug 3 call made a standard demo motion.
