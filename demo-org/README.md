# Demo orgs

Fictitious organizations for loading the BeMo Knowledge Base before demo and website capture. One folder per org; each has its own README, a `fact-sheet.md` that is the single source of truth for every name and number, and an `upload/` set that feeds the KB.

**The standing universe is Common Table (Becky, 2026-08-03): every demo and every website capture uses Common Table Food Pantry.** One fictional org everywhere means a prospect who watches a demo, a LinkedIn cut, and the website meets one organization with one set of names and numbers. This supersedes the Aug 3 founders-call choice of Wrenfield for the Super Demo; Wrenfield is retained only for the in-flight super-demo-60 (due Aug 9), and retires once that production closes.

| Folder | Org | Status |
|---|---|---|
| `common-table/` | Common Table Food Pantry | **Standing.** All demos and all website capture. The site's published fictional universe; its fact sheet marks [published] facts as upstream |
| `wrenfield/` | The Wrenfield Alliance | **Legacy.** Only for super-demo-60 recapture needs before Aug 9, 2026; do not use for new productions |

**The one rule, both orgs:** the fact sheet is the single source of truth. Every proper noun and number in every upload document traces to it. New proper nouns get web-searched for collisions before they go on a sheet.

**No blur:** Wrenfield content must never appear alongside Common Table content, and neither org may resemble the real cleared customers in `../../bemo-os/docs/customer-stories/`. Known legacy overlaps (shared first names Dana/Marcus/Priya, the Whitfield surname) are logged in `productions/common-table-kb-load/findings.md`; they are one more reason Wrenfield retires.

Everything in this tree is invented. Neither org is a customer, proof, or a claim about anything real.
